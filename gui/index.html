          About

          Open-source Windows triage tool

          RMM Hunter is built by Meidie at MDP Studio to help Windows users and small teams review suspicious remote access tools, Defender events, PowerShell activity, services, startup entries, scheduled tasks, and recent installers.

          The scanner is evidence-only at MVP stage. It does not exploit systems, bypass security, delete files, or automatically remove findings.
